# AccessPath — Accessibility Feedback for Public Places

AccessPath is a mobile application designed to help people discover, assess, and share accessibility information about public places. It enables users to make more informed decisions by exploring accessibility ratings, community feedback, and personalized location filters.

## Problem Statement

Information about accessibility in public places is often difficult to find or verify. People may not know whether a location has step-free access, working lifts, accessible washrooms, suitable seating, or clear wayfinding.

AccessPath aims to make this information easier to discover through structured accessibility assessments and community-driven feedback.

## Key Features

- **Accessibility Ratings:** Structured ratings for five categories:
  - Step-free access
  - Lifts
  - Accessible washrooms
  - Seating
  - Wayfinding
- **Overall Accessibility Score:** Generates a score based on available category ratings.
- **Personalized Filters:** Helps users find places that match their specific accessibility requirements.
- **Community Feedback:** Allows users to submit ratings and share their experiences.
- **AI-Generated Summaries:** Summarizes community feedback to highlight reported accessibility features and potential barriers.
- **Place Discovery:** Helps users explore public places and review their accessibility information.

## How It Works

1. Search for a public place.
2. Explore its accessibility ratings and overall score.
3. Filter locations according to individual requirements.
4. Read AI-generated summaries of community feedback.
5. Submit feedback to help other users make informed decisions.

## Technology Stack

- **Mobile Application:** Flutter
- **Programming Language:** Dart
- **Backend:** Python Flask (optional, depending on implementation)
- **Database:** SQLite or another suitable database
- **AI Integration:** Language model API for feedback summarization

*The final technology stack will depend on the implementation.*

## Project Goals

- Improve access to accessibility information.
- Support informed decision-making when choosing public places.
- Encourage community participation in accessibility assessments.
- Present accessibility information in a clear and user-friendly format.
- Use AI to make community feedback easier to understand.

## Responsible Information Design

AccessPath aims to distinguish verified information from community-reported experiences. Unknown or outdated ratings should be clearly identified, and accessibility scores should be interpreted alongside individual category ratings and available review information.
